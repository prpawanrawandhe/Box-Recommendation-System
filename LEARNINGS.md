# What I Learned

## 1. Django and Database
I learned how to create Django models and store box information in the database. I also learned how to retrieve data using Django ORM and QuerySets.

## 2. Recommendation Logic
I learned how to compare product dimensions with box dimensions. I used sorting dimensions to support rotation to handle product rotation and Python's min() function to select the lowest-cost suitable box.

## 3. Input Handling
I learned how to handle user inputs and check whether a product meets the box dimensions and weight capacity.

## 4. Automated Testing
I learned how to write automated tests using Django TestCase. I created tests to verify product dimensions, weight capacity, exact boundary values, and unsuitable products.

## 5. Challenges and Experience
One of the challenges I faced was understanding the browser's default behaviour of resubmitting a POST request when the page is refreshed. I used a searched flag to distinguish between the initial page load and a submitted search, so the appropriate message could be displayed.

## 6. Overall Experience
This assignment helped me understand how to build a small Django application from start to finish. I also learned the importance of testing and verifying application logic.
